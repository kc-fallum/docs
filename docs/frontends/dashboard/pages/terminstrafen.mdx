# Terminstrafen-Page (`src/components/pages/terminstrafen/`)

Die **Terminstrafen-Page** (`<terminstrafen-page>`) ist das Herzstück des aktiven Kegelabends. Sie stellt eine dynamische Matrix aus anwesenden Spielern und Strafenkatalog-Posten bereit, auf der Strafen während des Kegelns in Echtzeit per Klick oder Tastatur gezählt und synchronisiert werden.

## 2. Wie die Page gerendert wird (Task & Reaktivitätszyklus)

Die Komponente kapselt die Dateninitialisierung in einem `@lit/task`:

```typescript
private initialize = new Task(this, {
  task: async ([terminId]) => {
    const [termin, allKataloge, allSpieler] = await Promise.all([
      terminClient.getTerminById(terminId),
      katalogClient.getAllKatalog(),
      spielerClient.getAllSpieler()
    ]);
    // Sortierung der anwesenden Spieler und Übergabe an den Service
    this.service.init(terminId, termin, ...);
    return { termin, allKataloge, allSpieler };
  },
  args: () => [this.terminId]
});
```

* **Service-Subskription:** `connectedCallback()` abonniert Änderungen des `TerminstrafenService`. Bei jeder Zählung (`increment`, `decrement`) triggert der Service ein Re-Render der Zelle.
* **Dual-View-Modus (`view: Mode`):**
  * `live`: Rendert `<strafen-table>` – die interaktive Zähltabelle für den Spielabend.
  * `blueprint`: Rendert `<blueprint-widget>` – Visualisierung der Bahnaufstellung oder statistischer Auswertungen.
* **Excel/Spreadsheet-Export:** Über den Action-Header kann mit `spreadsheetService.exportTermin(terminId)` ein Spielbericht als Tabellendokument exportiert werden.
