# Nutzer-Page (`src/components/pages/nutzer/`)

Die **Nutzer-Page** (`<nutzer-page>`) verwaltet alle registrierten SSO-Benutzerkonten, Rollenzuweisungen und Sicherheitsstufen.

---

## 1. Die Dateien der Nutzer-Domäne

```text
src/components/pages/nutzer/
├── nutzer.page.ts         # Page-Komponente (Task, Suche, Profilkarten)
├── nutzer.form.ts         # NutzerFormService (Rollen- und Kontomodal)
└── nutzer.page.spec.ts    # Komponententests
```

---

## 2. Rendering & Rollenverwaltung

* **Lade-Task:** Ruft `authClient.getAllUsers()` ab.
* **Rollen-Matrix:** Erlaubt autorisierten Administratoren das Zuweisen von Berechtigungsrollen (`ADMIN`, `KASSENWART`, `STRAFENWART`, `USER`, `GUEST`).
* **Sicherheit:** Verwaltung von Kontosperrungen (`isActive`) und Auditierung von Letztanmeldungen.
