# Settings Entitäten (`settings` DB)

Der Settings Service speichert benutzerspezifische Einstellungen und Push-Abonnements in der relationalen Datenbank `settings`.

---

## 1. `SettingEntity`
Hält Benachrichtigungspräferenzen und WebPush-Subscriptions eines Benutzers fest.

* **Felder:**
  * `userId`: Eindeutige ID des Benutzers aus dem Auth-Service.
  * `subscription`: JSONB-Feld zur Ablage des Browser-spezifischen WebPush-Payloads (`endpoint`, `p256dh`, `auth`).
  * `notificationChannels`: Konfiguration aktiver Benachrichtigungskanäle (E-Mail, WebPush, Sound).
